## 🔌 Individual APIs

| API | Documentation | Description |
|---|---|---|
| Connector API | [docs.mews.com/connector-api](https://docs.mews.com/connector-api) | General-purpose API for accessing data and services in Mews |
| POS API | [docs.mews.com/pos-api](https://docs.mews.com/pos-api) | Integrates Point-of-Sale systems with Mews |
| Booking Engine API | [docs.mews.com/booking-engine](https://docs.mews.com/booking-engine) | Enables customers to create reservations directly in Mews |
| Channel Manager API | [docs.mews.com/channel-manager-api](https://docs.mews.com/channel-manager-api) | Manages distribution channels, availability, and reservations |
| Loyalty Partner API | [docs.mews.com/loyalty-partner](https://docs.mews.com/loyalty-partner) | Enables loyalty program integrations with Mews |
